Claude Code的可行的替代方案 2026.1.25

  1. 在 GitHub 继续深挖

  我可以：
  - 查看每位候选人的具体项目/仓库
  - 分析代码质量和技术栈
  - 查看他们的社交链接（很多 GitHub 用户会在 bio 中放 Twitter/LinkedIn 链接）

  2. 从学术期刊/论文找人才

  - 搜索机器人领域的顶级会议（ICRA, IROS, RSS）论文作者
  - 查找中国学者的论文和联系方式

  3. 从机器人实验室官网找

  - 搜索国内知名机器人实验室（清华 AI 实验室、中科院自动化所等）的成员页面

  4. 手动搜索指南

  我可以为你提供详细的搜索查询和步骤，你在平台上手动操作。
