# 从学术论文和实验室网站寻找机器人人才

## 1 一、原理分析

### 1.1 为什么学术论文和实验室网站是好来源？

1. **权威性强** - 顶级期刊/会议的论文作者经过同行评审
2. **技术前沿** - 论文反映最新研究进展
3. **信息完整** - 通常包含作者邮箱、所属机构、研究方向
4. **可追溯** - 可以从论文引用链找到更多相关研究者

### 1.2 人才画像特征

| 特征 | 来源 | 说明 |
|------|------|------|
| 🎓 教育背景 | 论文作者署名单位 | 可看出学校层次 |
| 🔬 研究方向 | 论文标题/摘要 | 机器人本体控制、规划、动力学等 |
| 💼 实力证明 | 发表会议/期刊级别 | ICRA/IROS/RSS 一顶会 = 硕博+实力 |
| 📧 联系方式 | 论文作者邮箱 | 直接沟通渠道 |
| 🏢 所属机构 | 实验室官网 | 可查更多成员信息 |

### 3.2 步骤 2：搜索论文（三种方式）

#### 3.2.1 方式 A：Google Scholar 搜索

**操作步骤：**

1. 访问 `scholar.google.com`
2. 搜索：`"humanoid robot" "University of Science and Technology of China"`
3. 筛选：选择近 3 年（2023-2026）
4. 记录：作者姓名、邮箱、所属实验室

#### 3.2.2 方式 B：会议官网搜索

以 ICRA 为例：

1. 访问 `icra2025.org` 或 `https://ras.papercept.net`（IEEE 会议索引）
2. 搜索关键词："Chinese"、"embodied"、"humanoid"
3. 查看作者名单，筛选中国学者

#### 3.2.3 方式 C：arXiv 搜索

1. 访问 `arxiv.org`
2. 选择分类：`cs.RO` (Robotics)
3. 搜索：`"humanoid" AND "China"`
4. 查看作者信息

---

### 3.3 步骤 3：获取实验室成员

**手动操作流程：**

1. 搜索 "清华大学 机器人实验室"
2. 找到官网 `tsinghua.edu.cn/robotics-xxx`
3. 浏览 `/People` 或 `/Members` 页面
4. 筛选：
   - 博士/博士后
   - 研究方向：本体设计、控制、规划
   - 项目经历：有实际机器人项目
5. 记录：姓名、邮箱、个人主页

**自动化思路（如果有开发能力）：**

```python
# 伪代码示例
def scrape_lab_members(base_url):
    members = []
    # 解析成员页面
    page = fetch(base_url + "/People")
    for person in page.select(".lab-member"):
        name = person.select("h3")[0].text
        email = person.select(".email")[0].text
        role = person.select(".role")[0].text  # PhD/Professor
        research = person.select(".research")[0].text
        if "robot" in research.lower() and "PhD" in role:
            members.append({
                "name": name,
                "email": email,
                "research": research
            })
    return members
```

## 6 六、注意事项

| 注意点 | 说明 |
|--------|------|
| ⚠️ **时效性** | 论文作者可能已毕业或换工作，需验证当前状态 |
| ⚠️ **语言障碍** | 部分实验室网站是中文，但页面结构类似 |
| ⚠️ **隐私** | 合规获取信息，避免骚扰式沟通 |
| ⚠️ **学术≠工程** | 论文强不代表工程能力强，需综合判断 |
| ℹ️ **交叉验证** | 多来源验证，避免找错人 |
