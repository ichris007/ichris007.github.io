> 本文档用于系统地向招聘者（猎头顾问和招聘HR）介绍Lifein ATS系统的功能特点、使用方法和核心价值。

## 1 招聘者的苦恼

告别Excel和邮件的混乱。系统提供可视化的招聘看板，将候选人从“新建”到“入职”的每一个环节（筛选、面试、评估、Offer）进行标准化状态流转。您可随时查看每个职位当前的招聘进度，不再遗漏任何一个人才。

## 2 为什么要用Lifein ATS系统？

Lifein ATS 是一套基于 Obsidian 构建的**知识驱动型**候选人追踪管理系统。它将传统的招聘管理系统与知识管理理念深度融合，通过双向链接、动态查询、自动化模板和数据可视化技术，将招聘工作中的信息孤岛彻底打通，为猎头顾问和招聘HR提供一站式的招聘全周期管理能力。

>ATS (Applicant Tracking System)，即候选人追踪系统。

这是一套高度**模块化、关联化、自动化、自由定制**的招聘管理系统，它将“客户-职位-人才-流程”通过双向链接紧密编织在一起。

通过五大核心模块（企业管理、职位管理、候选人管理、人才库）、三大支持模块（任务管理、知识管理、日记系统）和一个中央指挥仪表板，实现了从“接单”到“回款”的全生命周期管理。

**核心设计理念**：
以候选人为中心，以项目为主线，以数据和知识驱动决策。

## 3 系统特点与优势

### 3.1 核心架构

  1. 五大核心模块：
    - 企业管理（Client）
    - 职位管理（Projects）- 记录职位需求、客户信息、招聘进度
    - 候选人管理（Applications）- 追踪候选人状态、面试记录、反馈
    - 企业联系人管理（Contacts）- 
    - 人才库（Talents）- 存储潜在人才信息，多项目追踪
  2. 三大支持模块
	- 知识管理（Knowledge）
	- 日记系统（Journal）
	- 任务管理（Tasks）

### 3.2 主要功能

#### 3.2.1 Pipeline流程视图

系统采用精细化的招聘流程管理，分阶段追踪：
- 推荐前阶段：潜在人选 → 初步沟通 → 顾问评估
- 推荐后阶段：推荐 → 初筛 → 一面 → 二面 → 三面 → HR面 → 谈offer → 待入职 → 已入职
- 负反馈：简历淘汰 → 面试淘汰 → 人选放弃 → 客户放弃停


两个阶段，16种状态。

**推荐前阶段**

| 阶段 | 说明 |
|------|------|
| 潜在人选 | 从人才库筛选的初步匹配候选人 |
| 初步沟通 | 已建立联系，了解候选人意向 |
| 顾问评估 | 猎头顾问进行专业能力和意向评估 |

**推荐后阶段**

| 阶段 | 说明 |
|------|------|
| 推荐 | 简历正式推荐给客户 |
| 初筛 | 客户HR进行简历筛选 |
| 一面 | 第一次面试 |
| 二面 | 第二次面试 |
| 三面 | 第三次面试 |
| HR面 | HR综合面试 |
| 谈offer | 薪资谈判阶段 |
| 待入职 | Offer接受后等待入职 |
| 已入职 | 成功入职，项目完结 |

**负反馈管理**
- 简历淘汰 / 面试淘汰 / 人选放弃 / 客户放弃

#### 3.2.2 项目追踪（职位）

- 标准化职位信息：职位说明书、汇报关系、薪资范围、招聘要求等
- 目标公司地图：分层列出优先搜索的目标企业
- 面试流程：面试轮次、面试官、考核重点
- 过程管理：关键节点、Deadline提醒、进度追踪

#### 3.2.3 侯选人管理

- 全招聘周期管理：从初筛到入职的全流程
- 完整信息记录：跟进记录、面试记录、谈薪记录
- 匹配度和意愿度追踪：快速筛选出“高匹配+强意愿”的优质选手
- 多维度综合评价：避免碎片化、主观、随机评估

#### 3.2.4 人才管理

结构化的**人才数据库**
- 支持完整的人才信息录入：基本信息、工作背景、教育经历、技能专长
- 灵活的多项目管理：一个人才可同时参与多个招聘项目，独立追踪各项目状态（应聘岗位、沟通记录、面试记录等）
- 标签化分类：按人才来源（LinkedIn、GitHub、内推等）、活跃度、星级评分进行筛选
- 附件管理：简历、作品集、评估报告等文档集中存储

#### 3.2.5 企业/客户管理

- 企业资料库、信息记录
	- 企业状态：开发中，预合作，合作中，已暂停，已停止
- 联系人管理
- 项目状态筛选（进行中、已完成、已停止等）

#### 3.2.6 任务管理

清空大脑，统一管理待办事项。避免消耗关注力，遗忘重要任务。
- 任务与项目（岗位）、候选人、日期等自动关联
- 自动定制要跟进的任务
- 到期任务自动提醒
- 支持Dataview跨文件查询

定制，如
- 面试（带`#面试`）
- 入职（带`#入职`）

#### 3.2.7 知识管理

**标准化话术库**
- 初次联系候选人话术
- 薪资谈判的框架、方法和沟通技巧
- 候选人常见问题回应

**资源库**
- 行业研究报告
- 薪资市场数据
- 面试评估模板
- 竞品对标分析

#### 3.2.8 数据统计与分析

* 客户统计（按状态、优先级、行业等）
* 项目统计（按状态、优先级、行业等）
- 候选人数量统计（按不同阶段、状态、教育背景、企业、职位等）
- 回款/业绩统计（按类别、时间、客户等）
- 数据分析
	- 系统提供了精细化的候选人评估与沟通管理机制。通过多维度匹配和意向度评分，猎头顾问可以全面把握候选人情况。系统支持灵活的联系记录追踪，并配备星标优先级机制，确保关键候选人得到重点关注。标准化的模板确保数据录入的一致性和系统性。

>   系统提供了精细化的候选人评估与沟通管理机制。通过多维度匹配和意向度评分，猎头顾问可以全面把握候选人情况。系统支持灵活的联系记录追踪，并配备星标优先级机制，确保关键候选人得到重点关注。标准化的模板确保数据录入的一致性和系统性。
> 
>   面试管理同样高度标准化，包括详细的面试流程规划、面试官安排和时间节点控制。薪资预算透明化，offer谈判模块支持多维度薪资结构追踪。项目时间线和关键成功指标可视化，帮助团队精准把控招聘进展。
> 
>   风险登记表为项目提供前置预警，资源模块整合行业报告、话术模板和薪资市场数据，为猎头工作提供有力支撑。
>   
>   系统还支持与日记、待办事项的无缝关联，实现全方位工作协同。

### 3.3 招聘者受益
#### 3.3.1 对猎头顾问

1. **极速响应**：模板化操作，从拿到JD到建立项目只需1分钟，不再被琐事缠身。
2. **人脉复用**：强大的双向链接让你瞬间看清“这个人以前推荐过谁？”、“这个职位还有谁在流程里？”，激活沉睡资源。
3. **专业度提升**：内置话术库和行业知识库（如美团的组织架构），让你在客户面前显得更懂行。

#### 3.3.2 对招聘HR

1. **流程透明**：Dashboard 让招聘漏斗一目了然，数据驱动决策（如：哪个渠道简历淘汰率高）。
2. **资产沉淀**：员工离职不怕丢数据，所有人才资产、面试评价都留在本地库中。
3. **灵活定制**：不像传统SaaS那样死板，你可以随时增加字段（如“内推码”、“背调状态”），完全适配企业独特流程。


## 4 系统核心优势

| 维度 | 传统ATS | Lifein ATS |
|------|---------|------------|
| 数据所有权 | 云端服务商 | 本地Markdown，数据完全私有 |
| 灵活性 | 固定模板 | Obsidian生态，自由扩展 |
| 搜索能力 | 基础搜索 | Dataview高级查询，多维度筛选 |
| 链接能力 | 无 | 双向链接，天然关联候选人与项目 |
| 成本 | 按用户收费 | Obsidian免费，插件免费 |
| 迁移性 | 数据导出受限 | 纯文本格式，永久可用 |

**独特价值：**

1. **知识管理增强招聘** - 将招聘经验、行业洞察转化为可复用的知识资产
2. **个性化定制** - 完全掌控数据结构和展示方式
3. **长期人才库** - 一个候选人可追踪多年，跨项目复用
4. **零成本运维** - 无需IT支持

## 5 总结

Lifein ATS 将 Obsidian 的知识管理优势与招聘业务流程深度结合，创造了一种全新的「**知识驱动型**」招聘管理方式。无论是猎头顾问还是企业HR，都能从中获得：

1. **更清晰的流程视图**
2. **更高效的工作协同**
3. **更智能的数据分析**
4. **更丰富的知识沉淀**

这套系统的核心价值在于：把散落的招聘数据转化为可分析、可复用的知识资产，让招聘工作从「经验驱动」走向「数据驱动」。
