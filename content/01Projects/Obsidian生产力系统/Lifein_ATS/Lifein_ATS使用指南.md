## 1 使用指南

### 1.1 阶段 1：接单与立项

1. **创建企业档案**：使用模板创建企业文件（如 `美团.md`），录入公司简介、组织架构、竞对分析。
2. **创建职位项目**：使用模板创建项目文件（如 `战略商分负责人.md`），关联客户，录入JD、薪资预算、面试流程。
3. **制定策略**：在项目文件中填写“目标公司名单”和“话术”，利用 Tasks 插件列出 To-Do（如：建立50人候选人库）。

### 1.2 阶段 2：寻访与入库

1. **人才入库**：通过模板创建人才文件（如 `李四.md`），上传简历 PDF，标记技能标签、学历、当前公司。
2. **初步评估**：在人才档案中记录优势亮点、风险点。

### 1.3 阶段 3：推荐与推进

1. **发起应聘**：使用 Application 模板，输入 `李四` + `战略商分负责人`。
2. **系统自动执行**：
    - 生成 `李四_战略商分负责人_20260130.md` 文件。
    - 自动在 `李四.md` 中生成一条“推荐记录”。
    - 自动在 `战略商分负责人.md` 中生成一条“候选人名单”。
    - 自动在 `ATS_Dashboard.md` 的“初步沟通”标签页中显示该候选人。
3. **跟进记录**：在应聘文件中记录沟通细节、面试反馈、调整状态（如从“初步沟通”改为“一面”）。

### 1.4 阶段 4：监控与复盘

- **每日工作**：打开 `ATS_Dashboard.md`，查看 Todo List 安排今日工作。
- **进度监控**：点击 Pipeline 标签页，查看各阶段积压情况，识别卡点。
- **客户复盘**：回到 `美团.md`，查看该客户的所有职位进展和所有历史沟通日记。

### 1.5 场景一：开启新职位项目

**操作步骤：**

1. **创建项目文件**
   - 从模板新建职位项目文件
   - 填写客户名称、职位名称、薪资范围等基本信息
   - 设置项目DDL和紧急程度

2. **录入职位详情**
   - 完善JD内容：岗位职责、任职要求
   - 设定面试流程（轮次、面试官、时长）
   - 列出目标公司清单（分优先级）

3. **制定项目计划**
   - 使用任务清单规划招聘步骤
   - 设置各阶段时间节点
   - 关联DDL自动提醒

### 1.6 场景二：管理候选人

**搜索与筛选**
```
在人才库中按以下维度筛选：
- 匹配度（高/中/低）
- 意向度
- 当前状态
- 技能关键词
```

**新建候选人记录**
- 使用「ATS人才模板」创建候选人文件
- 完善个人信息、工作经历、技能专长
- 设置星级评分（3-5星标记重要性）

**追踪候选人状态**
- 在Application文件中更新候选人状态
- 记录每次沟通内容（电话、微信、邮件）
- 更新匹配度和意愿度评分

### 1.7 场景三：推进招聘流程

**面试安排流程**
1. 候选人进入下一阶段时，更新status字段
2. 在项目文件中记录面试安排
3. 面试后填写面试反馈表
4. 根据反馈决定推进或淘汰

**Offer谈判策略**
- 使用谈offer阶段的专属视图
- 记录候选人薪资期望
- 追踪Offer状态变化（有/无/谈判中/接受/拒绝）
- 记录入职日期

### 1.8 场景四：项目收尾

- 完成入职后更新状态为「已入职」
- 填写项目总结
- 将候选人移入「已入职」人才池
- 更新项目统计数据
