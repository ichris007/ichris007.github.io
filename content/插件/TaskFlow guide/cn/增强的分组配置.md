**分组编辑弹窗** （设置 -> 分组 ->编辑）新增了三个协同工作的控件，用于把一个分组限定到一组笔记，并在前端分组中展示。

```
ID
Name / 标签
Icon / 图标
Note selector property / 笔记筛选属性   ← 新增
Property values / 属性值筛选            ← 新增（多选，带搜索）
Limit / 上限                           ← 新增
```

## 0.1 笔记筛选属性（Note selector property）

- **标签：** "笔记筛选属性"
- **描述：** *"设置后，该组会显示与此前置属性匹配的笔记下拉列表。任务查询将使用所选笔记作为 `query.file`。"*
- **占位符示例：** `project`
- 设置（非空）后，该分组在视图上获得一个 [笔记选择器](笔记选择器.md)。
- **修改此属性会清空之前选中的「属性值」**，因为现在合法取值来自另一个 frontmatter 键。

## 0.2 属性值（Property values）

- **标签：** "属性值"
- **描述：** *"仅显示其属性包含所选值之一的笔记。留空以匹配任何非空值。"*
- 一个 **多选** 列表。每个取值带复选框；摘要行显示已选取值，未勾选时显示 *"任何非空值"*。
- **搜索框：** 当取值列表很长时，顶部的搜索框会随输入实时过滤选项（不匹配项隐藏而非删除）。
- 若整个 vault 中该属性没有任何取值，列表显示 *"没有笔记使用此属性"*。
- 即使当前没有笔记使用，之前保存的取值仍然可见，因此重构后也不会丢失已配置的取值。

## 0.3 上限（Limit）

- **标签：** "上限"
- **描述：** *"此组中每个查询的最大任务数（为空则使用查询自己的限制）."*
- 一个数字。设置后，它会作为 `limit N` 追加到分组内 **每个标签页的查询** 末尾，覆盖那些查询内部已写的 `limit`。详见 [任务上限](任务上限.md)。

## 0.4 演示步骤

1. 编辑一个分组 → 把 **笔记筛选属性** 设为 `project`（`project`是属性中已有的属性项名称）。
2. 打开 **属性值**，在搜索框中输入查找某个取值并勾选。（这里的取值是属性项的值）
3. 把 **上限** 设为 `5`。
4. 保存并观察看板：出现笔记下拉框，且该分组每个标签页上限为 5 条任务。
