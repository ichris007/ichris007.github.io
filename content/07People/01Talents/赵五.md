## 4 相关日记
```dataview
table without id
  file.link as 日期,
  regexreplace(L.text, "#\S+", "") as 内容
from "00Journal/01DailyNotes"
flatten reverse(file.lists) AS L
where contains(L.text, "[[" + this.file.name + "|") 
	OR contains(L.text, "[[" + this.file.name + "]]")
sort file.name desc
```
