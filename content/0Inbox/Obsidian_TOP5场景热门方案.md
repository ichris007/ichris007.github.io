# Obsidian TOP 5 场景 - 最受欢迎解决方案


## 1 🥇 场景 1：个人知识管理（PKM/Zettelkasten）

### 1.1 🏆 最受欢迎方案

#### 1.1.1 方案 A：Andy's Note System（Andy's Notes）

```
知名度: ⭐⭐⭐⭐⭐ (社区最著名)
来源: YouTube 频道 Andy's Notes

核心工作流:
  1. Daily Note (每日笔记)
     - 快速记录当天想法
     - 捕捉瞬时灵感
     - 每天一个新文件

  2. Literature Note (文献笔记)
     - 读书/读文章时记录
     - 一个文件一个主题
     - 引用来源

  3. Permanent Note (永久笔记)
     - 提炼核心观点
     - 独立完整的思考
     - 使用 Atomic Note 原则

  4. MOC (Map of Content)
     - 主题索引
     - 连接相关笔记
     - 知识网络入口

文件结构:
  📁 00 Inbox/
    └── ⏰ Daily Notes/
  📁 10 Projects/
  📁 20 Areas/
  📁 30 Resources/
  📁 40 Archives/

核心插件:
  ✅ Dataview - 数据查询
  ✅ Calendar - 日历视图
  ✅ Templater - 模板引擎
  ✅ Breadcrumbs - 面包屑导航
  ✅ Tag Wrangler - 标签管理

适用: 想要系统化 PKM 的用户
难度: ⭐⭐⭐ (中等)
```
